# Random Quote Generator in React.js  

This is a simple Random Quote Generator built using React.js as part of my journey to relearn and master React.  

## Features  

- Generate random quotes with a single click  
- Display the author's name (if available)  
- Responsive and user-friendly UI  

## Technologies Used  

- React.js  
- HTML & CSS  
- Quote API (or a predefined list of quotes)
